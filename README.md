# E-Book Store Management System

## Project Overview
A desktop application developed using Java Swing and Microsoft SQL Server to manage a bookstore.

## Technologies Used
- Java
- Java Swing
- Microsoft SQL Server
- JDBC
- NetBeans IDE

## Main Features
- Load records
- Insert new records
- Search for records
- Update records
- Delete records

## Database Structure
The project uses a database named `E_book`, which contains:

- Author
- Author_Book
- Book
- Publisher

The SQL database script is available in the `database` folder.

## Database Configuration
The application uses environment variables for database credentials:

- `EBOOK_DB_USER`
- `EBOOK_DB_PASSWORD`

## How to Run
1. Install Java JDK and Microsoft SQL Server.
2. Execute the SQL script inside the `database` folder.
3. Configure the database environment variables.
4. Open the project in NetBeans.
5. Make sure the SQL Server JDBC driver is available.
6. Run the application.
